# Data

`data/aps/` contains only the compact APS demonstration CSVs used by the
public 4-fold cross-validation example. The files are numbered for easier use:

- `1.csv` - original APS experiment `050`
- `2.csv` - original APS experiment `053`
- `3.csv` - original APS experiment `074`
- `4.csv` - original APS experiment `077`

Large full-part CSVs are intentionally not tracked. Users provide those files
locally when running `pi-tsad detect-part`.
